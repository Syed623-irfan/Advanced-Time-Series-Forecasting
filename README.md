# Advanced-Time-Series-Forecasting
Project Overview

This project explores forecasting a non-stationary time series using three major approaches:

SARIMAX – Classical statistical model

LSTM (Seq2Seq) – Recurrent neural network

Transformer – Attention-based deep learning model

The objective is to evaluate which model performs best for different forecast horizons (5-step, 10-step, 20-step).

📊 Key Features

Advanced preprocessing for non-stationary time series

Windowed dataset creation for supervised learning

Multiple forecasting horizons

Model training scripts for SARIMAX, LSTM, and Transformer

Evaluation using RMSE, MAE, MAPE

Plots for all models

Saved model weights (e.g., transformers_states.pth)
